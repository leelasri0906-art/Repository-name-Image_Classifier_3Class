# 🖼️ Three-Class Image Classification using Deep Learning

This project is a **Deep Learning-based Image Classification application** built using **TensorFlow, Keras, and Streamlit**. The application can identify and classify uploaded images into one of three predefined categories using a trained image classification model.

### 🚀 Live Demo

👉 **Try the application here:**
https://repository-name-imageclassifier3class.streamlit.app/

### ✨ Key Features

* 📷 Upload an image directly through the web application
* 🤖 AI-powered image classification
* 🧠 Deep Learning model built with TensorFlow/Keras
* 🔍 Predicts the image category automatically
* 📊 Displays the predicted class and confidence
* 🌐 Interactive Streamlit web interface
* ⚡ Simple and user-friendly design
* ☁️ Deployed online using Streamlit Community Cloud

### 🛠️ Technologies Used

### 🔄 How It Works

1. The user uploads an image.
2. The application preprocesses the image.
3. The trained TensorFlow/Keras model analyzes the image.
4. The model predicts one of the three predefined classes.
5. The predicted result and confidence are displayed to the user.

### 🎯 Project Objective

The main objective of this project is to demonstrate how **Deep Learning and Computer Vision** can be used to automatically classify images and how a trained machine-learning model can be converted into an accessible web application using Streamlit.
